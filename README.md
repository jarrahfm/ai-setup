# Open an AI chat, step by step

A one-page guide for a phone: choose an AI chat, follow its steps one screen at a time while you work on a laptop,
send a first request, then save the page as a file. It is published at https://jarrahfm.github.io/ai-setup/.

`index.html` is the whole guide; `img/` holds pictures of each chat's public start and sign-in screens.

The steps (`SETUP_ROUTES`, `TEST_PROMPT` and the route words in `TEXT`) are copied unchanged from the workshop talk,
`applied-ai-science-learning/presentation-short/index.html`. Change a step in both files. To publish a change,
commit and push to `main`; the page updates within a few minutes.
