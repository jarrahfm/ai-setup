Tips and tricks for the educators

Short habits that make AI work better for science teaching. Set up your project folder

Working with an AI chat

  1. New topic, new chat.A long chat fills the context window and uses up the usage limit faster. Paste the page into the new chat.
  2. One change per prompt.Then you can see what each change did. Keep a copy of every version that works, so you can always go back.
  3. Say who it is for and what they do.Say who the page is for, what it shows, what learners do and what they see. "A page about gravity" gets a general page; "12-year-olds drop a hammer and a feather" gets a lesson.
  4. Describe what you see, not the code."The feather falls through the floor" works better than guessing at a technical fix.
  5. Write down your standing instructions once.For example "simple English, label every unit". Put them in the app's settings, or in an AGENTS.md file in your project folder.
  6. Keep a prompt notebook.Save the prompts that worked and reuse them next time.

Checking the science

  1. Give it the source. Do not ask it for one.Paste your textbook page into the context, then find every number on the page in that source. An AI can hallucinate references.
  2. Ask "what did you assume?"After it builds a page, it often names rules or values you never gave it. Those are what you check.
  3. Check Arabic yourself.Nobody has tested how well these tools write science Arabic. Read every term before you share the page.

In the classroom

  1. Ask for one file that works offline."One index.html, no internet links." It then opens by double-click even when the classroom Wi-Fi is down.
  2. Test on the real screen.Try the page on the projector or a student tablet before the lesson.
  3. Never use real student data.Use made-up names and numbers in every prompt, and keep the project folder free of student records.

With an AI agent in a project folder

  1. One new folder for each project.Copy the whole folder before you ask for a big change.
  2. Stay in the default mode.Read every permission prompt before you press Allow. Never switch to "Full access" or "Turbo".

Never put personal data in a prompt or a project folder: no student names, phone numbers, civil ID numbers or passwords.
